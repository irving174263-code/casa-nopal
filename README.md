# Casa Nopal

Restaurante mexicano contemporáneo.

## Descripción

Plataforma web para consultar un menú,
realizar pedidos a domicilio y gestionar
las operaciones del restaurante.

## Objetivos

- Crear una experiencia web adaptable.
- Implementar un sistema de pedidos.
- Gestionar usuarios y productos.
- Integrar pagos electrónicos.
- Desplegar el proyecto en Internet.

## Tecnologías previstas

- HTML5
- CSS3
- JavaScript
- Node.js
- Express
- PostgreSQL
- Git y GitHub
